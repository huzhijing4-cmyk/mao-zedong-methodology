# mao-zedong-methodology

一个从《毛泽东选集》相关材料中提炼出的 Agent Skill，聚焦调查研究、矛盾分析、战略判断、群众路线与组织领导方法。

本 Skill 使用 [book-to-skill](https://github.com/virgiliojr94/book-to-skill) 生成。内容是结构化、综合性的摘要和方法提炼，不包含原书全文，也不替代权威版本或史料核验。源文件中的第六、七卷属于非正式“静火版”，已在 Skill 中单独标记来源风险。

## 安装

```bash
npx skills add https://github.com/huzhijing4-cmyk/mao-zedong-methodology --skill mao-zedong-methodology
```

## 文件

- `SKILL.md`：核心框架、使用边界、卷次与主题索引
- `chapters/`：七个按需加载的分卷文件
- `glossary.md`：关键术语
- `patterns.md`：可复用分析与组织流程
- `cheatsheet.md`：决策规则和快速检查表

## 使用边界

该仓库只用于个人、私有研究。历史语境中的政治、敌我和战争话语，不应直接映射到现代个人、团队或商业关系。重要事实、原句、写作日期和作者归属需另行核验。
